# Creative Image Production

A provider-aware workflow for turning a visual brief into generated or edited assets, with reviewable candidates, focused revisions, and reproducible delivery notes.

## What it does

- Clarifies the intended use, fixed constraints, and creative choices.
- Routes new images, edits, and supported composites to an appropriate available tool.
- Tracks the role of each reference image and preserves specified invariants.
- Reviews outputs for composition, exact text, fidelity, format, and visual defects.
- Records prompts and generation details when supported, without exposing private inputs.

## Use

Provide the image goal, intended use, exact copy or required elements, output dimensions, and any reference images. State which parts of an existing image must remain unchanged. If a paid external provider is required and the budget is unclear, the workflow asks before using it.

## Privacy

Keep private source images, identity references, credentials, and confidential product materials out of public Skill files and provenance records.
