# Visual QA Checklist

Inspect each output against the brief. Mark **pass**, **needs revision**, or **not checked**; note the evidence and limitation.

| Check | Review question | Status / note |
|---|---|---|
| Intended use | Does the image fit the audience, placement, and goal? | |
| Subject and composition | Are the requested subject, action, framing, and visual hierarchy clear? | |
| Fixed elements | Are exact copy, identity, product/UI, logo, and required objects preserved? | |
| Reference roles | Did each reference influence only the requested aspects? | |
| Text | Is all visible wording exact, legible, and free of extra or garbled text? | |
| Image quality | Are there visible artifacts, anatomy/object errors, unwanted duplicates, or inconsistent geometry? | |
| Crop and format | Are dimensions, aspect ratio, crop, file format, and transparency correct? | |
| Edit fidelity | For edits, are protected regions and source details unchanged? | |
| Delivery | Is the selected final distinguishable from drafts, with provenance where available? | |

Do not infer factual, legal, brand, or platform compliance from visual appearance alone. Record what needs human or source verification.
