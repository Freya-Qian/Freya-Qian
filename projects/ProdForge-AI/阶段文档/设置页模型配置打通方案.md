# 设置页模型配置打通方案（API Key 热更新）

> 项目：AI 产品工厂｜阶段 3 前端配套（设置页）｜日期：2026-09-22
> 目标：让「设置」页在网页里配置模型 API Key / 模型名 / Base URL，写回本地 `.env` 并**热生效，无需重启后端**。

---

## 一、现状与结论

- `app/config.py`：`Settings` 从 `projects/AI产品工厂/.env` 读 `MODEL_API_KEY / MODEL_NAME / MODEL_BASE_URL / MODEL_TIMEOUT / MODEL_MAX_RETRIES`，`settings = Settings()` 是模块级单例。
- `app/core/llm.py`：`LLMClient.__init__` 里 `self.api_key = api_key if api_key is not None else settings.model_api_key`——**每次新建 client 都读 settings 单例**。
- `app/services/task_worker.py` `process_task`（L143）：`client = LLMClient()`——**每个任务都新建 client**。

**结论**：只要更新内存 `settings` 单例的对应属性，下一个任务就会用新配置，**无需重启**。当前唯一缺的是「写回 .env + 更新 settings」的入口。

---

## 二、方案设计

```
前端设置页表单
   │ PUT /settings/model {model_api_key, model_name?, model_base_url?}
   ▼
后端 routes.update_model_settings
   │ 校验非空 → config.save_model_config(...)
   ▼
config.save_model_config
   ├─ 读 .env → 替换/追加 MODEL_* 行 → 原子写回（保持其他行不变）
   └─ 热更新内存 settings 单例（model_api_key / model_name / model_base_url）
   ▼
下一个 LLM 任务自动用新 Key（LLMClient() 每次新建读 settings）
```

## 三、后端改动（可直接照抄）

### 3.1 `app/config.py` 追加

```python
def save_model_config(model_api_key: str, model_name: str | None = None,
                      model_base_url: str | None = None) -> None:
    """写回 .env 并热更新内存 settings（无需重启）。"""
    env_path = PROJECT_DIR / ".env"
    lines = env_path.read_text(encoding="utf-8").splitlines() if env_path.exists() else []

    updates = {"MODEL_API_KEY": model_api_key.strip()}
    if model_name:
        updates["MODEL_NAME"] = model_name.strip()
    if model_base_url:
        updates["MODEL_BASE_URL"] = model_base_url.strip().rstrip("/")

    seen: set[str] = set()
    out: list[str] = []
    for line in lines:
        key = line.split("=", 1)[0].strip() if "=" in line else ""
        if key in updates:
            out.append(f"{key}={updates[key]}")
            seen.add(key)
        else:
            out.append(line)
    for key, val in updates.items():
        if key not in seen:
            out.append(f"{key}={val}")
    env_path.write_text("\n".join(out) + "\n", encoding="utf-8")

    # 热更新内存单例
    settings.model_api_key = updates["MODEL_API_KEY"]
    if "MODEL_NAME" in updates:
        settings.model_name = updates["MODEL_NAME"]
    if "MODEL_BASE_URL" in updates:
        settings.model_base_url = updates["MODEL_BASE_URL"]
```

### 3.2 `app/schemas.py` 追加

### 3.3 `app/api/routes.py` 追加（放文件靠前，`/settings` 不依赖 project）

```python
from app.config import settings, save_model_config  # 顶部 import 补上

@router.get("/settings/model")
def get_model_settings():
    """返回模型配置。Key 只回显尾 4 位，绝不回传完整 Key。"""
    key = settings.model_api_key or ""
    return {
        "configured": bool(key),
        "model_api_key": key[-4:] if len(key) >= 4 else "",
        "model_name": settings.model_name,
        "model_base_url": settings.model_base_url,
    }


@router.put("/settings/model")
def update_model_settings(payload: ModelSettingsUpdate):
    """保存模型配置：写 .env + 热更新（无需重启）。"""
    if not payload.model_api_key.strip():
        raise LLMError("INVALID_INPUT", "API Key 不能为空")
    save_model_config(
        payload.model_api_key,
        model_name=payload.model_name,
        model_base_url=payload.model_base_url,
    )
    return get_model_settings()
```

## 四、安全约束

| 约束 | 做法 |
|---|---|
| Key 不回显 | `GET /settings/model` 只返回尾 4 位 + `configured` 布尔 |
| Key 不入库 | 只写 `.env`（已 `.gitignore`），不进 SQLite、不进 events.jsonl |
| Key 不进日志 | 埋点/日志一律不写 `model_api_key` 值 |
| 幂等 | 重复保存同值无副作用；空 Key 返回 422 |
| 原子写 | `write_text` 整文件覆盖（MVP 单机可接受；如需更强用临时文件 + `os.replace`） |

## 五、前端设置页交互

### 5.1 页面元素

- **API Key**：`password` 输入框，placeholder「输入后保存，仅存本机 .env，不会上传/回显」。
- **模型名**：输入框，默认 `qwen-plus`。
- **Base URL**：输入框，默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`。
- **当前状态**：进入页面先 `GET /settings/model`，显示「已配置（尾 4 位 ··abcd）」或「未配置 —— 生成类功能将返回 503」。

### 5.2 交互流程

```
进入设置页 → GET /settings/model → 回填表单 + 状态
填写/修改 → 点「保存并生效」
  → PUT /settings/model
  → 成功：提示「已保存，无需重启，立即生效」；刷新状态显示尾 4 位
  → 失败：展示 error.message（422 空 Key / 其他）
```

### 5.3 可选：一键「测试连接」

- 后端补一个 `POST /settings/model/test`（用当前 settings 发一个 1 token 的极小请求），前端点「测试连接」显示「连通 ✅ / 失败 + 原因」。不阻塞本阶段，可后置。

### 5.4 与现有 503 的联动

生成类端点无 Key 时返回 `503 NO_API_KEY`（`error.code == "NO_API_KEY"`）。前端在任意生成失败遇到该 code 时，直接弹「去设置页配置 API Key」的跳转引导。

## 六、验收

1. 设置页保存 Key 后，**不重启后端**，立即新建项目跑澄清，能正常生成（不再 503）。
2. `GET /settings/model` 返回 `configured=true` 且 `model_api_key` 只有尾 4 位。
3. 空 Key 保存返回 422，且有前端提示。
4. `.env` 里 `MODEL_API_KEY` 被更新、其余行（BASE_URL/NAME/BUDGET/DEV_MODE）保持不变。
5. 埋点/日志/DB 中搜索不到完整 Key（可 `grep -r` 验证）。
