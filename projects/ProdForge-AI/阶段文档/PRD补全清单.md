## 必须问（本轮不超过 5 个）

### 问题 1：用户自备 API Key 时，模型厂商是"国内优先"还是"不限厂商"？
- **已选：A 国内优先（2026-09-21）**
- 为什么重要：项目想法、PRD、竞品证据这些内容会作为上下文发给模型。若允许填 OpenAI 等境外模型，项目资料就会出境，触碰隐私边界（D7）；若只限国内厂商，则数据不出境但用户可选范围变窄。
- 选项：A 国内厂商优先（阿里云百炼/DeepSeek 等，数据不出境）/ B 不限厂商（填什么用什么，接受数据可能出境）/ C 混合（默认国内 OpenAI 兼容接口，同时允许自定义 base_url + 模型名覆盖国内外）
- 推荐：C 混合（默认用国内 OpenAI 兼容接口，和现有两个项目同平台「阿里云百炼」可复用 Key；同时开放自定义 base_url，覆盖想用其他模型的用户）
- 不选的后果：纯 A 会挡住想用 Claude/GPT 的用户；纯 B 对隐私敏感的用户不友好，也偏离 PRD 17.5"项目资料为敏感数据"的定位

### 问题 2：单项目从想法到资料包的 token 预算上限，默认护栏设多少？
- **已选：B ≤10 元/项目（2026-09-21）**
- 为什么重要：PRD 17.3 只写了"≤ 预算上限（可配置）"，没给默认数字。用户自备 Key、成本自担，但没默认护栏时一次生成可能失控。
- 选项：A ≤ 5 元/项目 / B ≤ 10 元/项目 / C 不设默认（用户自行配置）
- 推荐：B ≤ 10 元/项目（一次完整孵化约 2-4 万 token，qwen-plus 约 0.1-0.2 元，10 元够跑且留足重试余量；超限提醒，不硬断）
- 不选的后果：不设默认时，用户批量重试或长文档生成可能产生意外账单；设太低（5 元）在重试多轮时容易触顶打断体验
