## 一、🔴 阶段 3 前置（前端依赖，需先做）

### S1 设置页模型配置端点（GET/PUT `/settings/model`）✅ 已完成

前端「设置」页依赖这两个端点配置模型 API Key / 模型名 / Base URL，要求**热生效、无需重启**。完整可照抄代码见《阶段文档/设置页模型配置打通方案.md》第三节，此处只列改动点：

| # | 文件 | 改动 |
|---|---|---|
| 1 | `app/config.py` | 追加 `save_model_config(model_api_key, model_name=None, model_base_url=None)`：读 `.env` → 替换/追加 `MODEL_*` 行（其余行不变）→ 原子写回 → 热更新 `settings` 单例 |
| 2 | `app/schemas.py` | 追加 `ModelSettingsUpdate`（`model_api_key` 必填、`model_name`/`model_base_url` 可选） |
| 3 | `app/api/routes.py` | 追加 `GET /settings/model`（Key 只回尾 4 位 + `configured` 布尔）与 `PUT /settings/model`（校验非空 → `save_model_config` → 返回同 GET） |

**为什么不用重启**：`task_worker.process_task` 每个任务 `LLMClient()` 新建，`LLMClient.__init__` 读 `settings.model_api_key` 单例——更新单例即对下个任务生效。

**安全约束**：Key 只回显尾 4 位；只写 `.env`（已 gitignore）不入库、不进 events.jsonl/日志；空 Key 返回 422。

**验收**：
1. 保存 Key 后**不重启后端**，新建项目跑澄清能正常生成（不再 503 NO_API_KEY）。
2. `GET /settings/model` 返回 `configured=true` 且 Key 只有尾 4 位。
3. 空 Key 保存返回 422。
4. `.env` 里 `MODEL_API_KEY` 被更新、其余行保持不变。
5. `grep -r` 全仓库搜不到完整 Key。
