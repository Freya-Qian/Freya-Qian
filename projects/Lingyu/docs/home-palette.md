# 首页配色约定

2026-10-02，Yizhitu 要求首页卡片色调一致：

- QQ 音乐、计时器、当前窗口、常用指令、随笔记、快速录音和照片卡片共用深蓝黑渐变底色。
- 普通卡片不加描边，移除灰色边缘高光，保留鼠标附近的淡青蓝悬停光晕。
- QQ 音乐保留既有彩色描边，计时器保留进度描边。
- 照片卡片及 mirror-stage 均设置统一背景，照片隐藏或删除后不会露出旧灰底。
- 配色统一定义在 renderer/styles.css 的 --home-coordinated-surface。

本地灵屿已更新并重启，展开界面已检查。照片保持现状，未删除用户照片。

所有其他 Tab（包括隐藏的剪贴板页）的卡片使用同一底色；输入框、设置项、导航选中态和悬停态均使用冷蓝青紫色板。保留待办分类及录音、错误等功能状态色。
