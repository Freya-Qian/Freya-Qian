## 产品经理验收步骤
1. 启动后端：`cd projects/AI-Avatar-Twin/backend && .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8100`
2. 启动前端：`cd projects/AI-Avatar-Twin/frontend && npm run dev`
3. 打开 `http://127.0.0.1:3000/`，按验证码登录。
4. 在「数字人设置」创建 Profile，上传本人照片，确认能看到 3D 风格化预览。
5. 在「选题与脚本」生成脚本，编辑后保存，再分别导出 Markdown / TXT。
6. 在「生成视频」创建任务，完成后到「我的视频」预览并下载 MP4 / 素材包 ZIP。
7. 刷新当前页面，确认 URL 中的项目上下文仍能恢复。

## 2026-09-22 追加：返回上一步与退出登录位置修复

### 参考结论
- Dashboard/Sidebar 模式适合把导航保持常驻，但账户/退出动作不能依赖被内容撑开的底部区域。
- 创作类工具常见做法是把账户动作放到顶部账户区或稳定 footer；本项目此前底部侧栏方案在部分视口下仍可能被挡，因此改为顶部操作栏。
- 返回上一步遵循浏览器历史优先；刷新后直接进入页面时，按业务流程回退。

### 本次调整
- 新增统一 `BackStep` 组件。
- 工作台、数字人设置、选题与脚本、生成视频、我的视频 5 页均增加「返回上一步」。
- 「退出登录」从侧栏底部移到工作区顶部操作栏，手机宽度下吸顶显示。
- 侧栏只保留主导航，减少底部遮挡和滚动冲突。
