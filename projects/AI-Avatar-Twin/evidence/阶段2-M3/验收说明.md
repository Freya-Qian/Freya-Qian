# M3 数字人视频与素材包 · 验收说明

> 阶段：2-3（M3）｜日期：2026-09-20

## 你能自己打开验证的地址
- 验收界面：**http://127.0.0.1:8100/**（需先启动后端）

## 照着点（启动 + 验证步骤）
1. 启动后端：
   ```bash
   cd projects/AI-Avatar-Twin/backend
   .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8100
   ```
2. 打开 http://127.0.0.1:8100/ ，登录 → 建项目 → 建数字人 Profile → 加信息源 → 抓取 → 摘要 → 选题 → 生成脚本。
3. 给 Profile 上传一张照片（照片会在视频里当数字人画面）。
4. 在脚本下方点「生成视频」→ 看状态从排队/生成中变成功。
5. 预览视频、下载 MP4、下载字幕、下载素材包 ZIP（打开看：MP4、封面、文案、来源清单、脚本、SRT）。
