# M2 账户与信息源 · 验收说明

> 阶段：2-2（M2）｜日期：2026-09-20

## 你能自己打开验证的地址
- 验收界面：**http://127.0.0.1:8100/**（需先启动后端）

## 照着点（启动 + 验证步骤）
1. 启动后端：
   ```bash
   cd projects/AI-Avatar-Twin/backend
   .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8100
   ```
2. 打开 http://127.0.0.1:8100/ ，输入手机号（测试环境任意 6-20 位数字）→「获取验证码」，页面上会显示测试验证码 → 输入 →「登录」。
3. 建一个项目（如「AI 工具号」）。
4. 建一个数字人 Profile（名称 + 表达风格 + 内容方向 + 口头禅 + 禁用词）。
5. 加一个信息源（网页 URL 或 RSS 或手动文本）→ 点「抓取」。
6. 在「抓取条目」里点「摘要」→「生成选题」→ 选一个 → 生成脚本（应符合你设的风格方向）。
7. 导出 Markdown / 纯文本。
8. 退出登录后，未登录访问会提示先登录；换一个手机号登录，看不到上一个账号的任何数据。
