# 第 3 阶段技术开发文档｜M4 正式前端

> 配套文档：PRD V1.2（rev53）、通用前端技术栈手册、M1/M2/M3 文档、技术适配声明。
> 本文档只覆盖 M4（正式前端）。后端接口已就绪，本阶段只做前端、不改后端业务。

## 一、阶段目标
- 交付范围：把 M1-M3 的「单 HTML 验收界面」升级为**正式 Web 前端**（Next.js + TypeScript + Tailwind），桌面与移动端都可用，覆盖 PRD 8 的核心页面。
- 阶段产物：`frontend/` 工程 + 复用现有后端 API + 响应式界面 + 测试 + 证据包。
- 页面范围（对齐 PRD 8，MVP 裁剪）：
  1. **登录页**：手机号 + 验证码登录。
  2. **工作台首页**：项目切换、信息源抓取状态、快捷入口。
  3. **数字人设置页**：Profile 管理（名称/风格/方向/口头禅/禁用词）、照片上传 + 授权、3D 风格化形象预览。
  4. **选题与脚本页**：信息源 → 条目 → 选题 → 脚本（流式）→ 编辑/版本/导出。
  5. **视频生成页**：生成视频（照片→3D风格化→口型驱动）、任务状态轮询、预览、素材包下载。
  6. **我的视频列表**：所有视频任务 + 预览/下载/重试。
- 明确不做：复盘页（PRD 7.9，P1 后置）、抖音授权发布（V1 不做）、声音克隆/多平台（V1 不做）。
- 验收标准：桌面（1280/1440px）与手机（390px）核心流程可走通；视频生成、脚本流式、素材包下载与后端真实联调通过。

## 二、技术适配摘要
- 采用前端手册 B 层默认：Next.js（App Router）+ TypeScript strict + Tailwind CSS + Lucide 图标 + Vitest/React Testing Library + Playwright + ESLint。
- 参考版本（与「脑洞游戏」前端一致）：Next.js 16.3.x、React 19.3.x、Tailwind CSS 4、Node 22 LTS、npm。
- 同源代理：Next.js `rewrites` 把 `/api/*` 代理到后端 `http://127.0.0.1:8100`（不暴露后端地址、不带密钥）。
- 鉴权：MVP 沿用现有后端 Bearer token 方案；token 存 `sessionStorage`（临时），上线部署时按手册改 HttpOnly Cookie。

## 三、技术栈与模型
- 无新模型。纯前端，复用后端文字模型（qwen-plus）、TTS（CosyVoice）、数字人（即梦 OmniHuman）、风格化（wan2.6-image）的既有接口。
- 依赖：next、react、react-dom、tailwindcss、lucide-react；开发依赖 typescript、eslint、vitest、@testing-library/react、@playwright/test。

## 四、环境与配置
- `frontend/.env.local`：
  ```dotenv
  NEXT_PUBLIC_BACKEND_URL=http://127.0.0.1:8100   # 后端地址（仅浏览器访问，密钥不在此）
  ```
- 启动：`cd frontend && npm install && npm run dev`，打开 http://127.0.0.1:3000（前端端口，与后端 8100 隔离）。
- 无新增密钥（前端不含任何 Key，鉴权 token 由登录接口返回）。

## 六、数据、资产与状态
- 前端不持久化业务数据（后端是唯一事实来源）；仅 `sessionStorage` 存 token、`localStorage` 存最近项目 ID。
- 前端状态机（对齐手册第九节）：每个页面区分 **加载 / 空 / 成功 / 失败 / 等待确认 / 断线恢复**；视频任务用「排队/生成中/成功/失败」展示。
- 项目 ID 放 URL（`/project/{id}` 或查询参数），刷新可恢复当前项目。
- 视频/图片预览用后端受保护接口 + `fetch` 带 token 取 blob URL（不用裸 `<a href>`，避免 token 失效）。

## 七、API / 契约
- 复用 M1-M3 全部后端接口（集中定义在 `lib/api`，不散落 fetch）。
- 统一错误结构 `{"error":{"code","message"}}`；前端把 HTTP 状态 + code 归一化成可读提示。
- 脚本生成走 SSE（`chunk` → `done`/`error`），断线时保留草稿并提示重试；视频生成走轮询（每 3 秒，最多 100 次）。

## 八、Prompt 设计
- 无新增 Prompt（纯前端）。

## 九、验收界面或纵向切片

## 十、测试要求
- 第一层：Vitest + React Testing Library（组件：登录表单、项目切换、任务状态展示、错误/空态）；typecheck + lint + build 作为交付门槛。
- 第二层：Playwright 核心闭环（登录 → 建 Profile/传照片 → 加信息源 → 生成脚本 → 生成视频 → 下载素材包）；真实浏览器验收桌面 + 手机宽度。
