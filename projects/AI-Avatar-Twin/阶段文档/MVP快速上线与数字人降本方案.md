## 三、本周要做的唯一一件事：照片→3D 渲染风风格化

### 为什么是唯一要补的
用户明确要求数字人 =「照片生成 3D 渲染风虚拟形象 → 形象口播」，**非照片直接开口**。当前缺"照片→3D 形象"这一步。

### 落地方案

**1. 新增 `app/services/stylize.py`**（照片→3D 渲染风形象）

- 用**阿里云百炼通义万相的图生图/图像编辑 API**（复用现有 DashScope Key，不用新接供应商）
- 具体模型名由开发查 DashScope 最新文档确认（图像编辑/风格化类模型）
- Prompt 模板：
  ```
  把这张照片转换成 3D 渲染风格的数字人形象，
  皮克斯动画质感，保留面部特征和五官比例，
  立体感强，适合做短视频口播主播，
  正面半身像，9:16 竖屏
  ```
- 输出：风格化后的形象图（存 `data/uploads/`）
- 失败降级：返回原照片（保证视频仍能出）

**2. `video_worker.py` 改输入链**（约 5 行）

```python
# 原来：
photo = _photo_path(profile)                    # 原照片
# 改成：
photo = _photo_path(profile)                    # 原照片
stylized = await stylize.stylize_avatar(photo)  # 3D 渲染风形象（新增）
# 后续口型驱动用 stylized，而非 photo
```

**3. 风格化结果缓存**（省钱省时）

- `AvatarProfile` 加 `stylized_asset_id` 字段，或本地按照片 hash 缓存
- 同一张照片只风格化一次，不重复调用图生图

**4. 配置**（`.env`）

```dotenv
STYLIZE_ENABLED=true
STYLIZE_MODEL=<通义万相图生图模型名，开发查文档>
```

### 验收标准
- [ ] 上传照片后，能生成一张"3D 渲染风"的形象图（保留本人面部特征）
- [ ] 用这张形象图 + 配音，能生成"形象开口说话"的视频
- [ ] 图生图失败时，自动降级用原照片，视频仍能出

## 四、MVP 上线后的降本路径（不阻塞 MVP）

> 关键认知：**MVP 的目标是验证需求，不是省钱。先上线，再降本。**

| 阶段 | 口型驱动 | 单条成本 | 月成本（内部试用） |
|---|---|---|---|
| **MVP（本周）** | 即梦 OmniHuman | 30 元/条 | 用 200 秒免费额度 + 少量付费，可控 |
| **上线后（1-2 周）** | onethingai + EchoMimic 自建 | ≈0.2 元/条 | ≈50～300 元 |

### 降本路径（上线后执行）
1. onethingai 租 RTX 4090（2.46 元/小时，按分钟计费，**开机中不计费**）
2. 部署 EchoMimic（口型驱动）+ SDXL/Flux（图生图，可替代阿里云 API 进一步降本）
3. 按需开关：有任务开机、跑完关机，月成本预计 50～300 元
4. 把 `video_worker` 的口型驱动从"即梦 API"切到"自建 EchoMimic"

### onethingai 计费规则（已确认）
- 标价按小时（4090 ≈ 2.46 元/小时），实际**按分钟扣费**（0.041 元/分钟）
- 仅"运行中"状态计费；**部署中/开机中/非运行中不扣费**
- 单条视频（生成约 4 分钟）GPU 成本 ≈ **0.16 元**
