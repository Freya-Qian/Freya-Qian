## 必须问（本轮不超过 5 个）

### 问题 1：第一版是内部小范围试用，还是直接对外公开？
- 为什么重要：决定企业认证、内容审核、并发扩容、肖像合规审计和部署成本，是交付范围的分水岭。
- 选项：A 内部小范围试用（几十人内）/ B 直接对外公开 / C 先内部、跑通后再放开
- 推荐：A 内部小范围试用（先验证闭环和合规，成本可控，和上一个项目同样节奏）
- 不选的后果：直接对外需先搞定企业认证、上传内容安全审核、肖像/声音授权审计、并发扩容，上线周期和费用大幅上升

### 问题 2：V1 登录方式用哪种？
- 为什么重要：影响账号体系、短信/认证服务商接入、开发量和上线审核周期（PRD 7.0 明确要账号，但未定具体方式）。
- 选项：A 手机号 + 短信验证码 / B 邮箱 + 验证码 / C 微信等第三方登录
- 推荐：A 手机号 + 短信验证码（抖音用户习惯、实名可追溯、便于肖像授权留痕；短信成本低）
- 不选的后果：第三方登录需开发者认证和平台审核，周期长；无账号无法满足 PRD 的数据隔离要求

### 问题 3：用户上传的本人照片/声音和生成的视频，存在哪、留多久、能否删除？
- 为什么重要：本人照片和声音属于敏感个人信息（肖像权/声音权），是合规核心（PRD 11.2），也决定部署位置和存储方案。
- 选项：A 全放国内云、用户可随时删除内容数据 / B 国内云 + 内容可删，但授权确认与审计记录保留 / C 允许境外服务
- 推荐：B（内容数据国内存储且用户可删；授权确认/审计记录按合规要求保留，用于追溯）
- 不选的后果：存境外或不可删有合规风险；不保留审计记录则无法追溯授权来源

### 问题 4：每月模型 + TTS + 数字人渲染的总费用护栏设多少？
- 为什么重要：视频渲染和 TTS 是持续计费项，无上限会成本失控（PRD 17.3 只定了单条 ≤3 元，未定月上限）。
- 选项：A ≤500 元/月 / B ≤1000 元/月 / C 先不限、按实际结算
- 推荐：A ≤500 元/月（约可跑 160 条视频，够验证闭环；和上一个项目同一量级）
- 不选的后果：无月护栏时，批量生成或误操作可能产生不可控账单

### 问题 5：公司能否办理云平台企业实名认证？
- 为什么重要：正式上线（含未来抖音授权发布、云资源实名）需要企业认证，通常要几天，建议与后端开发并行办。
- 选项：A 能办，现在就去办 / B 暂不能办，先本地或个人开发者跑通 / C 不确定
- 推荐：A 能办就现在办（周期几天，别拖到上线）
- 不选的后果：拖到上线时再办会卡住发布；先本地跑通虽可行，但上线前仍需补办
